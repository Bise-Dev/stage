Section 3 · Sync engine + event loops

Seven loops · three sequence flows · explicit github event mapping

The seven loops in the backend

#  loop                       trigger                       cadence              writes to
─  ──────────────────────  ──────────────────────────────  ───────────────────  ─────────────────────
1  webhook ingestion          github POST → /api/webhooks   reactive (no timer)  mirror + sync_event + SSE
2  outbox drain               new Outbox row enqueued        immediate + sweep    Outbox + mirror + sync_event + SSE
                              + periodic retry sweep         every 30s
3  reconciliation             scheduled per active workspace 5 min                mirror (delta repair) + sync_event + SSE
4  initial sync               on workspace create            one-shot             mirror (full pull) + sync_event + SSE
5  permission refresh         on access miss + scheduled     6h TTL refresh       UserRepoPermission cache
6  workspace archive sweep    scheduled                      1h                   Workspace.archived_at, webhook unregister
7  SSE broadcast              fires from loops 1/2/3/4       per event            (in-memory pub/sub)

Sync engine API (Python module, called by every loop)

sync_engine.apply_github_event(workspace, event)        # webhook + reconciliation
sync_engine.initial_sync(workspace)                     # on workspace create
sync_engine.enqueue_outbox(workspace, user, action, payload, etag?)
sync_engine.execute_outbox(outbox_row)                  # called by worker
sync_engine.reconcile_workspace(workspace)              # called by scheduler

# every mutation also writes a SyncEvent row + emits SSE

Flow A · Inbound (github → mirror)

github                  /api/webhooks/github           sync_engine                DB                SSE bus
  │                            │                          │                       │                   │
  │ POST event +               │                          │                       │                   │
  │  X-Hub-Signature-256       │                          │                       │                   │
  ├───────────────────────────►│                          │                       │                   │
  │                            │ verify sig (HMAC)        │                       │                   │
  │                            │ parse payload            │                       │                   │
  │                            │ extract delivery_id      │                       │                   │
  │                            │                          │                       │                   │
  │                            │ INSERT SyncEvent         │                       │                   │
  │                            │  (delivery_id UNIQUE)    ├──────────────────────►│                   │
  │                            │                          │                       │                   │
  │                            │ if collision → 200 OK    │                       │                   │
  │                            │ (already processed)       │                       │                   │
  │                            │                          │                       │                   │
  │                            │ resolve workspace(s)     │                       │                   │
  │                            │  by repo + pr_number     │                       │                   │
  │                            │                          │                       │                   │
  │                            │ for each workspace:      │                       │                   │
  │                            │  apply_github_event(...) ├──────────────────────►│                   │
  │                            │                          │ upsert mirror row     │                   │
  │                            │                          │  if event.updated_at  │                   │
  │                            │                          │  > mirror.updated_at  │                   │
  │                            │                          │                       │                   │
  │                            │                          │ append sync_event     │                   │
  │                            │                          │  (direction=inbound)  │                   │
  │                            │                          │                       │                   │
  │                            │                          │ emit_sse(workspace,   ├──────────────────►│
  │                            │                          │  event_summary)       │                   │
  │                            │                          │                       │                   │ ──► UI
  │                            │ 200 OK                   │                       │                   │
  │◄───────────────────────────┤                          │                       │                   │
  • Signature check first. Reject unsigned / mis-signed before any DB write.
  • Dedup via delivery_id UNIQUE. Constraint violation = duplicate delivery, return 200 immediately.
  • Resolve workspaces. One event may map to N workspaces (e.g., two workspaces on the same PR, one author-mode, one reviewer-mode). All get updated.
  • Idempotent upsert. If event.updated_at <= mirror.updated_at, skip (we have newer data).
  • SSE always fires on actual change. No-op upserts do not fire (avoid UI thrash).

Flow B · Outbound (user action → github)

user            REST view              sync_engine              Outbox/worker          github          DB     SSE bus
 │                  │                       │                        │                   │             │         │
 │ POST /api/...    │                       │                        │                   │             │         │
 ├─────────────────►│                       │                        │                   │             │         │
 │                  │ enqueue_outbox(...)   │                        │                   │             │         │
 │                  ├──────────────────────►│                        │                   │             │         │
 │                  │                       │ INSERT Outbox row      │                   │             │         │
 │                  │                       │  status=pending         │                   │             │         │
 │                  │                       │  capture mirror etag    │                   │             │         │
 │                  │                       ├────────────────────────│──────────────────►│             │         │
 │                  │                       │                        │                   │             │         │
 │                  │                       │ async_task('drain', id) ├──────────────────►│             │         │
 │                  │ 202 Accepted          │                        │                   │             │         │
 │◄─────────────────┤  + outbox_id          │                        │                   │             │         │
 │                  │                       │                        │ pick up row        │             │         │
 │                  │                       │                        │ lock: pending → in_flight       │         │
 │                  │                       │                        │ precondition check (re-read     │         │
 │                  │                       │                        │  mirror; if already target,     │         │
 │                  │                       │                        │  skip API → succeeded with note)│         │
 │                  │                       │                        │                                 │         │
 │                  │                       │                        │ call github (PyGithub/httpx,    │         │
 │                  │                       │                        │  If-Match: precondition_etag)   │         │
 │                  │                       │                        ├────────────────────────────────►│         │
 │                  │                       │                        │                                 │         │
 │                  │                       │                        │ ◄─── 200 OK + response          │         │
 │                  │                       │                        │                                 │         │
 │                  │                       │                        │ update mirror from response     │         │
 │                  │                       │                        │  (new github_id, etag, etc.)    │         │
 │                  │                       │                        │ Outbox.status=succeeded         │         │
 │                  │                       │                        │ append sync_event (outbound)    │         │
 │                  │                       │                        │ emit_sse(...)                   ├────────►│
 │                  │                       │                        │                                 │         │ ──► UI
  • REST view is non-blocking. 202 Accepted + outbox_id, UI polls or listens via SSE for completion.
  • Precondition check before push. Prevents redundant API calls when state is already target (e.g., "close PR" on closed PR).
  • ETag-protected writes where github supports them. Otherwise mirror-state check.
  • Failure paths:
    • 5xx / network → retry with exponential backoff; cap at N attempts → failed.
    • 409 / 412 (ETag mismatch) → conflicted, never auto-overwrite, UI surface.
    • 403 / 404 → failed, no retry.

Flow C · Reconciliation (drift repair)

scheduler (5min)           sync_engine                  github                    DB                SSE bus
   │                            │                          │                       │                   │
   │ tick                       │                          │                       │                   │
   ├───────────────────────────►│ reconcile_workspace(ws)  │                       │                   │
   │                            │                          │                       │                   │
   │                            │ GET /repos/.../pulls/{n}  │                       │                   │
   │                            ├─────────────────────────►│                       │                   │
   │                            │ ◄─── PR snapshot         │                       │                   │
   │                            │                          │                       │                   │
   │                            │ GET /repos/.../pulls/{n}/comments                 │                   │
   │                            │ GET .../reviews          │                       │                   │
   │                            │ GET .../commits/{sha}/check-runs                  │                   │
   │                            │ GET .../commits/{sha}/check-suites                │                   │
   │                            │ (parallel; conditional with If-None-Match etags)  │                   │
   │                            ├─────────────────────────►│                       │                   │
   │                            │                          │                       │                   │
   │                            │ ◄── 200 changes / 304 no-change                  │                   │
   │                            │                          │                       │                   │
   │                            │ diff(remote, mirror)     │                       │                   │
   │                            │ for each delta:          │                       │                   │
   │                            │  apply_github_event(...) ├──────────────────────►│                   │
   │                            │                          │ upsert + sync_event   │                   │
   │                            │                          │ (event_type='reconcile_*')                │
   │                            │                          │                       │                   │
   │                            │                          │ emit_sse if changes   ├──────────────────►│
   │                            │ done                     │                       │                   │ ──► UI
  • Per-workspace task — only active workspaces run reconciliation. Idle (no SSE clients, no recent activity) skip.
  • Conditional GETs (ETags) minimize rate-limit burn. 304 = nothing changed, no body to diff.
  • Parallel fetches — PR + comments + reviews + check runs concurrently via httpx async.
  • Drift events labeled. sync_event.event_type prefix = reconcile_* to distinguish from webhook ingest in audit log.
  • This is the safety net. If 1 webhook delivery is lost, reconciliation catches it within 5 min.

SSE channel mechanics

  • One channel per workspace. Endpoint GET /api/workspaces/{id}/events streams.
  • Multi-user fan-out — multiple connections per channel; each event copied to all connections.
  • Per-event recipient filter — a draft-changed event includes target_user_id; the SSE dispatcher drops it for other connections in the channel.
  • In-process bus for v1: Python pub/sub structure inside Django. When backend is scaled to multiple processes later, swap to Redis pub/sub (one-line change).
  • Heartbeat every 25s to keep proxies happy.
  • Replay-on-reconnect: client passes Last-Event-ID, server replays sync_event rows since that id. (Acts as event log for SSE.)

Concurrency invariants

  • Outbox row drain holds a row-level lock (SELECT ... FOR UPDATE); concurrent workers cannot double-drain.
  • Mirror upserts are gated by (github_id, updated_at) comparison — last-write-wins by github time, not arrival time.
  • Draft writes are gated by (workspace, user) UNIQUE; concurrent UI tabs of the same user are serialized.
  • Storyline writes are gated by storyline.updated_at If-Match (sent by UI); stale clients get a 409 conflict surface.
  • SyncEvent insertion is append-only; never updated; no contention.

What changed vs section 1 v1

  • "Local backend" → "Backend (deployable)". One service, many users.
  • Auth layer added. OAuth-login for identity. Admin PAT for github API. Session cookies for user state.
  • UserRepoPermission cache added to DB. Authz derived from github permission, cached with TTL.
  • Tunnel arrow now dev-only. Prod: github → public URL → backend. Dev: github → tunnel/smee → backend.
  • Git ops removed from the diagram. Storyline = DB row (D2 revised). File content may still be fetched via github API on demand (no need for local clone).

SSE fan-out (multi-user)

Each workspace has a server-side event channel. When the sync engine emits a change, it broadcasts to ALL users currently subscribed to that workspace's channel. Per-user filtering happens before publish: a draft change owned by user A is not broadcast to user B.

  • Workspace-level events (mirror updates, storyline edits, AI-doc updates) → broadcast to everyone in channel.
  • Per-user events (your draft was saved) → unicast to that user's connection within the channel.

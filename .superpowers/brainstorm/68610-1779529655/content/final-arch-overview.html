The ownership map at a glance

Backend owns (forever)
• User identity (OAuth login)
• Workspace (the PR pointer)
• Storyline + StorylineFile (file order, intros)
• IntroComment (threaded discussion on intros)
• AIAnalysisDoc + AIAnalysisFile
• UserRepoPermission cache (not consulted in v1)
Backend owns (transient)
• DraftReview (one per user per workspace)
• DraftComment (queued until publish)

On publish → pushed to github → DB row deleted.
DB never holds a published comment.
Github owns (truth · read on demand)
• PR object (title, body, head/base, state, draft, merge state)
• Diff files + file contents
• Review comments · issue comments · reactions
• Review objects · review threads (resolved)
• Check runs · workflow runs · status checks
• Branch protection · CODEOWNERS · permissions
Cross-the-wire flows
UI → Backend native route → DB (sync) → 2xx
UI → Backend proxy route → Github API (sync) → return gh response
UI → Backend publish route → DB read draft → Github write → DB delete draft → 2xx

No background jobs. No webhooks. No SSE in v1.
